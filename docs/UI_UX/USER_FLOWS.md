# User Flows

## Scan and share
Home → Scan → capture pages → review → crop/enhance → optional OCR → filename/output settings → create PDF → validate/save → native share sheet.

## Import and merge
Home/Tools → Merge → OS picker → select files → reorder → validate → process → verify output → save/share.

## OCR and searchable PDF
Open/import document → select OCR → select verified language → process locally → review text → save searchable PDF or export text → index locally if requested.

## Password protection
Open PDF → Protect PDF → enter/confirm password → choose supported security options → process locally → reopen output with password → save as new file. Never log or persist the password in plaintext.

## Redaction
Open PDF → Redact → select region/text where supported → preview redactions → confirm irreversible operation → sanitize/rewrite output → search/extract test content → save new file.

## Lifetime purchase
Settings/Pro → show one-time price and benefits → store purchase sheet → pending/success/cancel/error → update entitlement → remove ads → allow restore flow. Do not block document tools when billing is offline.

## Permission denied
Feature request → explain why permission is needed → user denies → offer supported alternate route or settings guidance → app remains stable.

## Local reminder
Document → reminder settings → choose date/time → request OS permission if needed → schedule locally → edit/cancel from reminder list.
