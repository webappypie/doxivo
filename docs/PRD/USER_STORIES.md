# User Stories

## Scanning
- As a student, I can scan several pages into one PDF so I can submit notes or assignments.
- As an office user, I can manually adjust crop corners when auto-detection fails.
- As a user, I can retake a blurry page without losing previous pages.
- As a user, I can enhance a scan while keeping the original capture recoverable.

## PDF tools
- As a user, I can merge selected PDFs in a chosen order.
- As a user, I can split a large PDF into selected ranges.
- As a user, I can compress a PDF and see the actual size change before deciding to keep it.
- As a user, I can protect a PDF with a password and verify it opens correctly.
- As a user, I can add a signature or watermark and preview the result.

## OCR and search
- As a user, I can extract text without uploading my document.
- As a Hindi/English user, I can search recognized text in supported languages.
- As a user, I can create a searchable PDF while preserving the page's appearance.

## Organization and privacy
- As a user, I can organize documents with folders, tags, and favorites.
- As a user, I can search recent documents quickly.
- As a privacy-conscious user, I can use core tools without creating an account.
- As a user, I can delete a document and understand what data will be removed.
- As a user, I can use document tools with the device offline.

## Monetization
- As a free user, I can use useful core features with reasonable ads.
- As a buyer, I can make a one-time purchase to remove ads.
- As a buyer, I can restore the entitlement after reinstall or device change, subject to store rules.
- As a buyer, I can continue using local document features when store services are unavailable.
