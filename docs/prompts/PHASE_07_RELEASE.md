# Phase 07 — Hardening and Release

## Tasks
- Run all unit/widget/integration/document integrity tests.
- Run full PDF_TEST_CORPUS.
- Run airplane-mode and network-inspection suite.
- Stress large PDFs, batch jobs, low storage and app lifecycle interruption.
- Review accessibility, dark mode, text scaling and localization.
- Audit dependencies, licenses and known vulnerabilities.
- Verify redaction and encryption independently.
- Test ads, purchase, restore and revocation.
- Complete store assets, privacy disclosures, signing and release configuration.
- Produce release notes and known-limitations document.
- Run internal/beta release and triage feedback.

## Go/no-go
Do not release with unresolved document loss/corruption, document uploads, critical/high security issues, misleading encryption/redaction, broken lifetime entitlement, or missing required disclosures.

## Final report
Include build IDs, platform/OS/device matrix, tests and results, benchmark numbers, privacy verification, known limitations, store readiness, and rollback/hotfix plan.
